Translator Profile

Salas John

English-to-Urdu Christian translation for books and resources intended to serve Urdu-speaking readers.

I work on translating Christian literature from English into Urdu, with a focus on communicating the source author's intended meaning in clear, natural Urdu. Christian books often contain biblical references, theological concepts, and language shaped by a particular tradition. These require careful attention to context as well as wording.

Areas of translation

  • Christian books and manuscripts
  • Bible studies, devotionals, and teaching resources
  • Theological and discipleship materials
  • Sermons and other Christian ministry content

How a project can begin

See the translation project process for an overview of the steps we can discuss before a project begins.

For a new project, we can discuss the intended audience, manuscript length, terminology preferences, schedule, budget, and review arrangements before work begins. The appropriate rights holder's written permission or licensing approval should be secured before translating or publishing copyrighted material. Project terms and author or publisher approval can be agreed in writing.

I do not claim that every project has the same scope or review process; these details should be discussed transparently for each assignment.
